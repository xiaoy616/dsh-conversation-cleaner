# dsh-conversation-cleaner

A DeepSeek Harness sidebar plugin for managing conversations and their generated files.

## Features

- **Conversation overview** — total memory usage and file count for the current conversation, shown in the sidebar.
- **File actions** — open, reveal in Finder, or delete files generated by a conversation.
- **Workspace access** — open the conversation workspace folder directly.
- **Conversation cleanup** — permanently delete a conversation together with its local session logs.

## Install

From npm:

```bash
dsh plugin add dsh-conversation-cleaner
```

Or from a local checkout:

```bash
dsh plugin add /path/to/dsh-conversation-cleaner
```

The plugin is declared through `cordis.patch.yml` and exposes both a host entry (`index.js`) and a web client entry (`client.js`).

## Package layout

| File | Purpose |
| --- | --- |
| `index.js` | Host-side plugin entry: file operations, deletion, workspace access |
| `client.js` | Web client entry: sidebar UI |
| `cordis.patch.yml` | DSH bundle patch declaration |
| `locale/en.json`, `locale/zh.json` | UI strings (English / Chinese) |
| `icon.svg` | Plugin icon |

## Requirements

- DeepSeek Harness with the `@deepseek-ai/dsh-client-ui-sidebar` and `@deepseek-ai/dsh-client-ui-layout` client packages.
